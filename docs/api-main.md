# T27 integer-core API

Unreleased 0.2.0 candidate. Exact balanced-ternary integer arithmetic and 27-trit
words. Vectors are LSB-first; text is MSB-first. Fixed words wrap modulo 3^27.
See the numeric contract and proof pages included in this API reference.
Floating-point RFCs, CPU/ISA, hardware and OS work are outside this installed API.
